# agent-costbook 1.2.0

AR and other clients can now read reviewed price and capability facts directly
over anonymous HTTP, without installing AC or supplying a consumer key. The
separate local administrator service remains compatible.

- Independent public application: `agent_costbook.public_api:create_public_app`.
- Reviewed, immutable SQLite publication: 17 OpenRouter price cards, 5 agents,
  and 33 model-effort rows, with source timestamps and explicit exclusions.
- M0–M6 estimates marked `public-reference`; missing usage remains missing.
  Private overrides, M7 measurements, and all online writes are forbidden.
- API/schema version 1, publisher and independent price/capability hashes,
  full-response ETags, conditional GET, bounded bodies/batches and instance limits.
- Docker distribution and native Vercel FastAPI adapter. Data survives restarts
  as an immutable bundled publication; updates retain the publisher and history.

Conditional prices for 12 models are not flattened into misleading universal
rates. Gemini cache-write storage conditions, AA score redistribution, private
subscription data, and a generic usage-assumption table are not included.
